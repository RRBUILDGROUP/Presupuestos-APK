# Presupuestos — Salto Francisco Sacabollos

Aplicación para el celular. Acá está sólo el archivo para instalarla.

## Descargar

**[→ Descargar la última versión](../../releases/latest)**

Bajá el archivo `app-release.apk`.

## Instalar

1. Abrí el archivo descargado desde el celular.
2. Android va a avisar que la app no viene de Play Store. Es lo esperado:
   permitile la instalación desde esa fuente, esa única vez.
3. Confirmá.

## Actualizaciones

**No hace falta volver acá.** Una vez instalada, las versiones nuevas llegan
solas por WiFi desde la PC del taller: la app avisa y se actualiza sola.
